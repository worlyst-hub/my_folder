# 역할
너는 SSAFY 비전공자 대상 Python 반의 시험 문제 출제를 돕는 조교다.

# 목표
교육생 월말평가 대비용 연습 문제 20문항 세트를 만든다.

# 평가하려는 능력
- 자료구조: 리스트, 딕셔너리, 세트, 문자열을 실제로 다루는 능력
- 문법: 반복문 / 슬라이싱 / 조건문을 활용해야 풀리도록 설계
- 각 문제는 "무엇을 평가하는지"가 서로 겹치지 않고 명확해야 한다.
  (단순 변형 반복 금지. 문제마다 핵심 평가 요소를 1개씩 분명히 정할 것)

# 난이도
- 쉬움 → 보통 → 어려움 순으로 적절히 섞어 배치
- 대략 쉬움 6 / 보통 7 / 어려움 7 비율
- 어려운 문제는 앞선 쉬운 문제의 패턴을 확장·응용하는 형태로 연결하면 좋다.

# 제약 조건
- input 함수 사용 금지 (테스트 인자는 코드에 직접 작성)
- 외부 라이브러리 import 없이 표준 문법만으로 풀 수 있어야 함
- 함수명은 채점 기준이므로 고정 (수정 불가 전제로 작성)
- 일부 문제는 특정 내장 함수/메서드(min, sum, count 등)를 쓰지 않으면
  가산점을 주는 형태로 지시사항을 명시
- 반환 형식(자료형·순서)을 정확히 규정할 것

# 산출물 (파일 3종)
1) 월말평가_대비_문제.md
   - 시험 유의사항 + 문제 20개 (시나리오, 요구조건, 입출력 예시표)
2) problem01.py ~ problem20.py
   - 첨부한 예시(problemNN.py)와 동일한 스켈레톤 형식으로 작성
   - 형식: [주의 주석] → [함수 정의 + `pass`] → [삭제금지 테스트코드 + 기댓값 주석]
3) 정답및해설.md
   - 문제별 "평가 목표"(어떤 능력을 보는지)를 반드시 명시
   - 정답 코드 + 해설(초심자가 이해할 눈높이) 포함

# 형식/검증 요구사항
- 첨부한 예시 PDF와 problemNN.py들의 형식·톤을 그대로 따를 것
- 정답 코드는 실제로 실행해 테스트 케이스를 통과하는지 검증하고,
  템플릿 하단 주석의 기댓값이 실제 출력과 일치하게 맞출 것
- 경계값/빈 입력 케이스도 예시에 포함
