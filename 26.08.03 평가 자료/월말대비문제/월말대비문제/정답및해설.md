## 문제 01 — `sum_list`  (쉬움)

**🎯 평가 목표**  
리스트를 반복문으로 순회하며 값을 누적(accumulation)하는 기본 능력을 평가한다. sum() 내장 함수 없이 직접 총합 로직을 구현할 수 있어야 한다.

**✅ 정답 코드**
```python
def sum_list(numbers):
    total = 0
    for n in numbers:
        total += n
    return total
```

**📝 해설**  
합을 담을 변수 total을 0으로 시작한 뒤, 리스트를 한 번 순회하며 total에 더해 나간다. 이것이 가장 기본적인 '누적' 패턴이다. 빈 리스트가 들어와도 0이 반환되어 안전하다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `sum_list([10, 20, 30])` | `60` |
| `sum_list([0, 0, 0])` | `0` |
| `sum_list([5, 15, 25, 55])` | `100` |
| `sum_list([100])` | `100` |

## 문제 02 — `count_high`  (쉬움)

**🎯 평가 목표**  
리스트를 순회하며 조건(비교 연산)을 만족하는 원소의 개수를 세는 능력을 평가한다. 조건부 카운팅 패턴의 이해 여부를 본다.

**✅ 정답 코드**
```python
def count_high(scores):
    cnt = 0
    for score in scores:
        if score >= 90:
            cnt += 1
    return cnt
```

**📝 해설**  
카운터 cnt를 0으로 두고 리스트를 순회한다. 각 점수가 90 이상이면 cnt를 1 증가시킨다. '경계값(90)'을 >= 로 포함하는지 정확히 판단하는 것이 핵심이다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `count_high([90, 60, 95, 88])` | `2` |
| `count_high([100, 90, 90])` | `3` |
| `count_high([10, 20, 30])` | `0` |
| `count_high([89, 91, 90, 45])` | `2` |

## 문제 03 — `count_char`  (쉬움)

**🎯 평가 목표**  
문자열도 반복문으로 한 글자씩 순회할 수 있음을 이해하고, 특정 문자와 일치하는지 비교하여 개수를 세는 능력을 평가한다. str.count() 없이 직접 구현할 수 있어야 한다.

**✅ 정답 코드**
```python
def count_char(word, target):
    cnt = 0
    for ch in word:
        if ch == target:
            cnt += 1
    return cnt
```

**📝 해설**  
문자열을 for로 돌리면 한 글자(char)씩 꺼내진다. 꺼낸 글자가 target과 같으면 카운트한다. 리스트 카운팅과 완전히 같은 패턴이며, 문자열이 '순회 가능한 자료형'임을 확인하는 문제다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `count_char('banana', 'a')` | `3` |
| `count_char('banana', 'b')` | `1` |
| `count_char('ssafy', 's')` | `2` |
| `count_char('python', 'z')` | `0` |

## 문제 04 — `reverse_string`  (쉬움)

**🎯 평가 목표**  
문자열 슬라이싱, 특히 스텝(step)을 -1로 주는 뒤집기 슬라이싱([::-1])을 활용할 수 있는지 평가한다.

**📝 해설**  
슬라이싱 word[시작:끝:스텝] 에서 스텝을 -1로 주면 문자열이 뒤에서부터 읽혀 통째로 뒤집힌다. 시작/끝을 비워두면 전체 범위를 의미한다. 반복문으로 result = ch + result 처럼 앞에 붙여도 되지만, 슬라이싱이 훨씬 간결함을 익히는 문제다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `reverse_string('python')` | `nohtyp` |
| `reverse_string('ssafy')` | `yfass` |
| `reverse_string('a')` | `a` |
| `reverse_string('level')` | `level` |

## 문제 05 — `total_price`  (쉬움)

**🎯 평가 목표**  
딕셔너리의 값(value)들을 순회하며 누적하는 능력을 평가한다. .values() 또는 키 순회를 통해 값에 접근하는 방법을 이해했는지 본다.

**✅ 정답 코드**
```python
def total_price(cart):
    total = 0
    for price in cart.values():
        total += price
    return total
```

**📝 해설**  
딕셔너리는 기본적으로 순회하면 '키'가 나온다. 값만 필요하므로 cart.values()로 값들만 꺼내 누적한다. cart[key] 처럼 키로 접근해 더해도 결과는 같다. 빈 딕셔너리는 0을 반환한다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `total_price({'apple': 1000, 'banana': 500})` | `1500` |
| `total_price({'milk': 2500})` | `2500` |
| `total_price({'a': 100, 'b': 200, 'c': 300})` | `600` |
| `total_price({})` | `0` |

## 문제 06 — `unique_count`  (쉬움)

**🎯 평가 목표**  
세트(set)가 '중복을 자동으로 제거'하는 자료구조임을 이해하고, 이를 활용해 서로 다른 원소의 개수를 구할 수 있는지 평가한다.

**입출력 검증**

|---|---|
| `unique_count([1, 2, 2, 3, 3, 3])` | `3` |
| `unique_count(['a', 'b', 'a', 'c'])` | `3` |
| `unique_count([5, 5, 5, 5])` | `1` |
| `unique_count([])` | `0` |

## 문제 08 — `highest_scorer`  (보통)

**🎯 평가 목표**  
딕셔너리를 순회하며 '최댓값을 가진 키'를 찾는 능력(최적값 추적, best-value tracking)을 평가한다. 값을 비교하면서 그때의 키를 기억해 두는 패턴이 핵심이다.

**✅ 정답 코드**
```python
def highest_scorer(scores):
    best_name = None
    best_score = None
    for name in scores:
        if best_score is None or scores[name] > best_score:
            best_name = name
            best_score = scores[name]
    return best_name
```

**📝 해설**  
'현재까지 최고 점수(best_score)'와 '그 학생 이름(best_name)'을 함께 기억한다. 딕셔너리를 순회하며 지금 학생 점수가 기존 최고보다 크면 갱신한다. > 로 비교하므로 동점일 때는 먼저 나온 사람이 유지된다. 최솟값/최댓값 찾기의 표준 패턴이다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `highest_scorer({'kim': 90, 'lee': 85, 'park': 95})` | `park` |
| `highest_scorer({'a': 70, 'b': 70, 'c': 60})` | `a` |
| `highest_scorer({'solo': 100})` | `solo` |
| `highest_scorer({'x': 30, 'y': 80, 'z': 80})` | `y` |

## 문제 10 — `common_items`  (보통)

**🎯 평가 목표**  
두 리스트의 공통 원소를 구하는 문제로, 세트의 교집합 개념과 결과를 다시 리스트로 변환·정렬하는 능력을 평가한다.

## 문제 11 — `count_vowel_consonant`  (보통)

**🎯 평가 목표**  
문자열을 순회하며 조건(모음 여부)에 따라 분기하고, 결과를 딕셔너리에 나눠 담는 능력을 평가한다. 'in 문자열'로 소속 여부를 판단하는 것이 핵심이다.

**✅ 정답 코드**
```python
def count_vowel_consonant(word):
    result = {'vowel': 0, 'consonant': 0}
    for ch in word:
        if ch in 'aeiou':
            result['vowel'] += 1
        else:
            result['consonant'] += 1
    return result
```

**📝 해설**  
결과 딕셔너리를 먼저 0으로 초기화한다. 문자열을 순회하며 'ch in "aeiou"'로 모음이면 vowel을, 아니면 consonant를 1 증가시킨다. 'in 문자열'은 그 글자가 문자열 안에 있는지 검사하는 아주 유용한 표현이다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `count_vowel_consonant('python')` | `{'vowel': 1, 'consonant': 5}` |
| `count_vowel_consonant('apple')` | `{'vowel': 2, 'consonant': 3}` |
| `count_vowel_consonant('aeiou')` | `{'vowel': 5, 'consonant': 0}` |
| `count_vowel_consonant('xyz')` | `{'vowel': 0, 'consonant': 3}` |

## 문제 13 — `longest_word`  (보통)

**🎯 평가 목표**  
문장을 split()으로 단어 리스트로 나눈 뒤, 길이를 비교하며 가장 긴 단어를 찾는 최적값 추적 능력을 평가한다.

**✅ 정답 코드**
```python
def longest_word(sentence):
    words = sentence.split()
    best = words[0]
    for word in words:
        if len(word) > len(best):
            best = word
    return best
```

**📝 해설**  
sentence.split()은 공백 기준으로 문장을 잘라 단어 리스트를 만든다. 첫 단어를 임시 정답(best)으로 두고 순회하며 더 긴 단어가 나오면 갱신한다. > 로 비교하므로 같은 길이면 먼저 나온 단어가 유지된다. 8번(최댓값 추적)과 같은 패턴을 '길이' 기준으로 적용한다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `longest_word('i love python programming')` | `programming` |
| `longest_word('a bb ccc dd')` | `ccc` |
| `longest_word('hello world')` | `hello` |
| `longest_word('ssafy')` | `ssafy` |

## 문제 14 — `count_frequency`  (어려움)

**🎯 평가 목표**  
딕셔너리로 빈도수를 세는 핵심 패턴('없으면 만들고, 있으면 더한다')을 구현할 수 있는지 평가한다. 이후 문제들의 토대가 되는 중요한 패턴이다.

**✅ 정답 코드**
```python
def count_frequency(items):
    result = {}
    for item in items:
        if item in result:
            result[item] += 1
        else:
            result[item] = 1
    return result
```

**📝 해설**

## 문제 15 — `group_by_length`  (어려움)

**🎯 평가 목표**  
키에 리스트를 값으로 두고 원소를 그룹으로 모으는('없으면 빈 리스트 생성 후 append') 패턴을 평가한다. 딕셔너리 안에 리스트를 담는 중첩 구조 이해가 핵심이다.

**✅ 정답 코드**
```python
def group_by_length(words):
    result = {}
    for word in words:
        length = len(word)
        if length not in result:
            result[length] = []
        result[length].append(word)
    return result
```

**📝 해설**  
단어의 길이를 키로 사용한다. 그 길이가 아직 딕셔너리에 없으면 빈 리스트를 먼저 만들어 둔 뒤, append로 단어를 추가한다. 14번의 '없으면 생성' 패턴을 값이 '리스트'인 형태로 확장한 것으로, 그룹핑의 표준 패턴이다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `group_by_length(['sky', 'sea', 'tree', 'a', 'go'])` | `{3: ['sky', 'sea'], 4: ['tree'], 1: ['a'], 2: ['go']}` |
| `group_by_length(['cat', 'dog', 'bird'])` | `{3: ['cat', 'dog'], 4: ['bird']}` |
| `group_by_length(['one'])` | `{3: ['one']}` |
| `group_by_length([])` | `{}` |

## 문제 16 — `first_unique_char`  (어려움)

**🎯 평가 목표**  
딕셔너리로 각 글자의 빈도를 먼저 센 뒤, 다시 순회하며 '딱 한 번만 나온 첫 글자'를 찾는 2단계(빈도 집계 -> 순서 탐색) 사고를 평가한다.

**✅ 정답 코드**
```python
def first_unique_char(word):
    counts = {}
    for ch in word:
        if ch in counts:
            counts[ch] += 1
        else:
            counts[ch] = 1
    for ch in word:
        if counts[ch] == 1:
            return ch
    return ''
```

**📝 해설**  
먼저 딕셔너리로 각 글자의 등장 횟수를 센다(14번 패턴). 그 다음 문자열을 '원래 순서대로' 다시 훑으며 횟수가 1인 첫 글자를 만나면 바로 반환한다. 두 번째 순회에서 원본 문자열을 도는 것이 '가장 먼저'라는 순서 조건을 지키는 비결이다. 끝까지 없으면 빈 문자열을 반환한다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `first_unique_char('swiss')` | `w` |
| `first_unique_char('aabbcc')` | `` |
| `first_unique_char('python')` | `p` |
| `first_unique_char('aabbc')` | `c` |

## 문제 17 — `merge_stock`  (어려움)

**🎯 평가 목표**  
두 딕셔너리를 합치되 같은 키는 값을 더하는 병합 능력을 평가한다. 한 딕셔너리를 복사(또는 순회 누적)하고 다른 딕셔너리를 반영하는 처리를 이해했는지 본다.

**✅ 정답 코드**
```python
def merge_stock(stock1, stock2):
    result = {}
    for item in stock1:
        result[item] = stock1[item]
    for item in stock2:
        if item in result:
            result[item] += stock2[item]
        else:
            result[item] = stock2[item]
    return result
```

**📝 해설**  
먼저 stock1의 내용을 그대로 결과에 복사한다. 그 다음 stock2를 순회하며, 이미 있는 상품이면 수량을 더하고(+=), 없는 상품이면 새로 등록한다. 14번의 '있으면 더하고 없으면 생성' 패턴을 두 딕셔너리 병합에 응용한 것이다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `merge_stock({'apple': 3, 'banana': 2}, {'banana': 5, 'cherry': 1})` | `{'apple': 3, 'banana': 7, 'cherry': 1}` |
| `merge_stock({'a': 1}, {'b': 2})` | `{'a': 1, 'b': 2}` |
| `merge_stock({'x': 10}, {'x': 5})` | `{'x': 15}` |
| `merge_stock({}, {'new': 7})` | `{'new': 7}` |

def only_in_first(list1, list2):

## 문제 19 — `mask_id`  (어려움)

**🎯 평가 목표**  
슬라이싱으로 앞부분을 남기고, 문자열 반복(*)과 len()을 조합해 나머지를 가리는 복합 문자열 처리 능력을 평가한다.

**✅ 정답 코드**
```python
def mask_id(user_id):
    visible = user_id[:3]
    hidden_count = len(user_id) - 3
    if hidden_count <= 0:
        return user_id
    return visible + '*' * hidden_count
```

**📝 해설**  
앞 3글자는 user_id[:3]으로 남긴다. 가려야 할 글자 수는 전체 길이에서 3을 뺀 값이다. 그 수가 0 이하이면(3글자 이하) 가릴 게 없으므로 원본을 그대로 반환한다. 그렇지 않으면 '*' * 개수로 별표를 만들어 앞부분에 이어 붙인다. 슬라이싱, 문자열 반복, 조건 처리를 모두 쓰는 문제다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `mask_id('jungssafy')` | `jun******` |
| `mask_id('kimssafy')` | `kim*****` |
| `mask_id('abc')` | `abc` |
| `mask_id('ab')` | `ab` |

## 문제 20 — `run_length_encode`  (어려움)

**🎯 평가 목표**  
문자열을 순회하며 '연속으로 같은 글자'의 개수를 세는(직전 글자 기억 + 카운트 유지·초기화) 상태 추적 능력을 평가한다. 가장 종합적인 난이도의 문제다.

**✅ 정답 코드**
```python
def run_length_encode(word):
    if not word:
        return ''
    result = ''
    current = word[0]
    count = 1
    for ch in word[1:]:
        if ch == current:
            count += 1
        else:
            result += current + str(count)
            current = ch
            count = 1
    result += current + str(count)
    return result
```

**📝 해설**  
빈 문자열이면 바로 ''을 반환한다. 첫 글자를 current로, 개수 count를 1로 시작한다. 두 번째 글자부터(word[1:] 슬라이싱) 순회하며, 직전 글자와 같으면 count를 늘리고, 달라지면 지금까지의 'current+count'를 결과에 확정한 뒤 current와 count를 새 글자로 초기화한다. 반복이 끝나면 마지막으로 세던 묶음을 잊지 말고 한 번 더 붙여야 한다. 이 '마지막 처리'가 가장 자주 틀리는 부분이다.

**입출력 검증**

| 호출 | 반환값 |
|---|---|
| `run_length_encode('aaabbc')` | `a3b2c1` |
| `run_length_encode('abc')` | `a1b1c1` |
| `run_length_encode('aaaa')` | `a4` |
| `run_length_encode('')` | `` |
