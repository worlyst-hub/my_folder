## 문제 10. RAG의 정의로 가장 적절한 것을 고르시오.

1. 언어 모델이 외부 지식 없이 내부 파라미터만으로 답변하는 방식
2. 검색 모듈을 통해 문서를 불러오고, 언어 모델이 생성 과정에 활용하는 방식
3. 강화학습 기반으로 모델의 보상을 조정하는 방식
4. 모델의 계산량을 줄이기 위해 차원 축소만 수행하는 방식

> **정답: 2**
> RAG(Retrieval-Augmented Generation)는 외부 데이터베이스나 문서로부터 관련 정보를 검색하여 언어 모델의 생성 과정에 활용하는 방식이다.

## 문제 16. 희소검색기(Sparse retriever)와 밀집검색기(Dense retriever)를 비교한 설명으로 옳지 않은 것을 고르시오.

1. Sparse는 의미적 매칭이 어렵고 Dense는 의미적 매칭이 가능하다
2. Dense retriever는 사전 학습과 파인튜닝이 필요한 경우가 많다
3. TF-IDF는 simple keyword 기반 검색 방식이다
4. Dense retriever는 계산량이 더 적고 확장성이 더 좋다

> **정답: 4**
> Dense retriever는 벡터 임베딩과 유사도 계산이 필요하여 Sparse retriever(TF-IDF, BM25 등)보다 **계산량이 많고** 확장성이 더 떨어지는 경향이 있다.
