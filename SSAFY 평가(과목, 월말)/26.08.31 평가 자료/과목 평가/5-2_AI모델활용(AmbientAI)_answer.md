## Q34. TTA(Test-Time Adaptation)의 주요 목적은?

A. 테스트 데이터의 라벨을 예측한 후 모델을 재학습하기 위함이다.
B. 테스트 데이터의 분포를 파악하여, 모델이 새로운 환경에 적응하도록 하기 위함이다.
C. 학습 데이터의 평균과 분산을 고정하여 과적합을 방지하기 위함이다.
D. 테스트 데이터를 이용해 모델의 모든 가중치를 다시 초기화하기 위함이다.
E. 학습 단계에서 모델의 복잡도를 줄이기 위해 사용된다.

> **정답: B**
> TTA는 테스트 데이터의 분포를 반영해 모델을 조정함으로써 성능 저하를 막는 것이 목적이다. 학습을 새로 하는 것이 아니라, 테스트 중에 일부 계층(주로 Batch Norm)을 테스트 데이터에 맞게 조정한다.

## Q35. TENT와 SAR의 주요 차이점으로 옳은 것은?

A. TENT는 학습 데이터를 이용해 BatchNorm을 업데이트하고, SAR은 테스트 데이터를 이용한다.
B. SAR은 불확실성이 높은 샘플을 더 적극적으로 업데이트에 반영한다.
C. TENT는 테스트 데이터의 엔트로피를 최소화하며, SAR은 그 과정을 더 안정적으로 수행하도록 개선한다.
D. TENT는 파라미터 업데이트를 하지 않지만, SAR은 전체 네트워크를 다시 학습한다.
E. 두 기법 모두 테스트 시점에 모델을 변경하지 않는다.

> **정답: C**
> TENT는 엔트로피를 최소화하는 방식으로 모델을 적응시키지만, 노이즈가 큰 샘플이 들어오면 불안정해질 수 있다. SAR은 엔트로피가 낮은 확실한 샘플만 선택해 업데이트하여 적응 과정을 더 안정적으로 만드는 기법이다.

## Q36. TPT(Test-time Prompt Tuning) 기법의 핵심 아이디어로 가장 적절한 것은?

A. 테스트 이미지 대신 학습 이미지를 사용해 프롬프트를 미리 튜닝한다.
B. 테스트 이미지의 여러 증강본을 활용해 예측의 일관성을 높인다.
C. 이미지 인코더의 통계값을 고정하여 모델을 안정화한다.
D. 테스트 시점에서 모델 전체 파라미터를 다시 학습한다.
E. 프롬프트 대신 모델의 가중치를 직접 업데이트한다.

> **정답: B**
> TPT는 테스트 이미지의 증강본 여러 개를 생성하고, 그중 엔트로피가 가장 낮은 샘플들을 이용해 텍스트 프롬프트를 조정하여 예측 일관성을 향상시키는 기법이다.

## Q37. PromptAlign 기법의 주요 목표는?

A. 테스트 이미지에 맞는 새로운 언어 모델을 학습한다.
B. 프롬프트를 무작위로 변경해 테스트 데이터를 다양화한다.
C. 학습 데이터와 테스트 데이터의 분포 차이를 줄이기 위해 통계적 정렬을 수행한다.
D. 테스트 데이터의 레이블을 예측한 뒤 프롬프트를 재훈련한다.
E. 학습 데이터만을 이용해 테스트 적응 없이 프롬프트를 미리 고정한다.

> **정답: C**
> PromptAlign은 각 계층별 통계(평균, 분산)를 정렬하여 학습-테스트 간 분포 차이를 줄이는 비지도 TTA 기법이다.

## Q39. 적응적 센싱(Adaptive Sensing)에 대한 설명으로 가장 올바른 것은?

a) 모델의 파라미터 수를 증가시켜 더 많은 데이터 분포를 학습하는 기법이다.
b) 센서 파라미터를 조절하여 다양한 데이터를 모델이 학습한 영역(ID) 안으로 이동시키는 기법이다.
c) 학습 데이터의 양을 늘려서 분포 이동 문제를 근본적으로 해결하는 기법이다.
d) 모델 일반화와 동일한 개념으로, 학습 단계에서 적용되는 기법이다.

> **정답: b**
> 적응적 센싱은 모델을 키우는 대신 센서(카메라 등)의 파라미터를 조절하여, 데이터를 모델이 잘 인식할 수 있는 영역으로 이동시키는 기법이다. 인간이 안경을 쓰는 것과 유사한 접근으로, 추론 단계에서 실시간으로 적용된다.

## 문제 71. 초거대 AI의 스케일링 전략에 대한 설명으로 가장 잘못된 것을 고르시오.

1. AI 모델의 성능은 모델 크기, 학습 데이터 양, 컴퓨팅 자원이 증가함에 따라 향상되는 경향이 있다
2. 물리 환경에서 직접 구동하는 피지컬 AI에서도 모든 경우의 수를 학습 데이터로 준비하는 전략이 여전히 효율적이다
3. 초거대 AI 전략은 "데이터 더! 모델 더 크게!"라는 방식으로 규모로 보험을 드는 접근이다
4. 스케일링 법칙의 한계로는 비용 폭증, 환경 문제, 데이터 고갈 등이 있다

> **정답: 2**
> 실제 물리 환경은 조명·날씨·센서 상태처럼 변수가 사실상 무한하므로, 모든 경우의 수를 학습 데이터로 미리 준비하는 것은 불가능하다. 그래서 모델의 지식 영역(ID)을 무한정 넓히는 대신, 센서 파라미터를 조절해 **데이터를 모델이 아는 영역으로 끌어오는** 적응적 센싱 같은 접근이 필요하다.
