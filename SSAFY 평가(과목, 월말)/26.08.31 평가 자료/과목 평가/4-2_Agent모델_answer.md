## Q31. 에이전트 기반 심층 연구 관련 문제

1~8번 각 문항의 선택지는 퀴즈 파일 참조.

> **정답: 1-b / 2-d / 3-d / 4-b / 5-b / 6-b / 7-a,b,d / 8-b**
>
> 주요 해설:
> - **3번**: 기존 RAG는 고정된 파이프라인으로 검색하지만, 에이전트는 추론 중에 필요에 따라 언제 무엇을 검색할지 동적으로 결정하므로 오류 전파를 줄일 수 있다.
> - **4번**: <탐색> 단계는 웹 내용을 읽고 유용한 정보를 단기 저장소에 수집하는 역할이다.
> - **7번**: 리드 에이전트는 질문 분석, 계획 수립, 결과 종합 및 지시를 담당하고, 직접 검색 수집(c)은 하위 에이전트 역할이다.
> - **8번**: TTS(Test-Time Scaling)는 추론 단계에서 더 많은 연산을 수행해 성능을 높이는 접근이다.

## 문제 49. 다음 중 Tool Learning이 필요한 이유로 옳지 않은 것을 고르시오.

1. 모델이 환각을 줄이고 정확한 정보 처리 능력을 높이기 위해
2. 코드 실행이나 데이터베이스 조회 등 모델이 스스로 수행할 수 없는 작업을 위해
3. 모든 정보를 파라미터로 학습해 도구 없이도 완전한 지식 기반을 구축하기 위해
4. 전문 소프트웨어와 연계된 실용적 응용을 가능하게 하기 위해

> **정답: 3**
> Tool Learning의 핵심 이유는 모델의 한계를 외부 도구로 보완하는 것이다. 모든 것을 파라미터로 학습하는 것은 불가능하며, 이것은 Tool Learning이 필요한 이유가 아니라 오히려 반하는 주장이다.

## 문제 69. MCP가 해결하려는 핵심 문제로 옳지 않은 것은?

1. 서로 다른 회사의 도구를 LLM이 안정적으로 사용할 수 있게 통합
2. 외부 시스템과 연결 시 발생하는 보안, 권한 문제 관리
3. LLM이 도구를 직접 신뢰할 수 있도록 완전 자동 의사결정 제공
4. 기능 확장을 위한 범용 인터페이스 표준화

> **정답: 3**
> MCP(Model Context Protocol)는 LLM과 외부 도구·데이터를 잇는 표준 **인터페이스 규약**이다. 연결 방식을 표준화하고(1, 4) 보안·권한을 관리할(2) 뿐, 어떤 도구를 언제 쓸지에 대한 의사결정을 대신하거나 도구의 신뢰성을 보증해 주지는 않는다. 판단은 여전히 모델과 시스템 설계자의 몫이다.

## 문제 74. Agent의 Memory가 중요한 이유는?

1. LLM의 계산 속도를 높이기 위해
2. 데이터 크기 감소를 위해
3. GPU 메모리 절약을 위해
4. 외부 지식의 축적과 재활용을 위해

> **정답: 4**
> 여기서 말하는 Memory는 하드웨어 메모리(1~3)가 아니라, 에이전트가 탐색·대화 과정에서 얻은 정보를 저장하고 다시 꺼내 쓰는 장치다. 단기 메모리는 현재 검색 결과를 임시 보관하고, 장기 메모리는 축적된 지식을 이후 작업에 재활용한다.
