## Q1. AI, ML, DL의 관계에 대한 설명으로 옳은 것은?

① ML은 AI와 DL의 상위 개념이다. # AI가 ML의 상위 개념임. ML은 DL의 상위 개념
② AI는 반드시 ML을 사용해야 한다. # 아님, 휴리스틱 기반 최적화 알고리즘과 규칙 기반 시스템이 있음
*③* ML은 AI의 한 부분으로, 데이터로부터 학습을 수행한다. # 맞음
④ 규칙 기반 시스템은 ML의 한 분야이다. # 규칙 기반 시스템은 AI의 한 분야임
⑤ ML은 사람이 직접 코딩한 규칙을 그대로 사용하는 방식이다. # ML은 데이터로부터 모델이 자체적으로 학습하는 방식임


## Q2. Feature와 Label에 대한 설명으로 옳지 않은 것은?

① Feature는 모델이 예측에 사용하는 입력 정보이다. # 맞음
② Label은 모델이 예측하려는 정답, 즉 학습의 목표이다. # 맞음
③ Feature와 Label의 분포와 관계가 학습 결과를 결정한다. # 맞음
*④* Feature는 반드시 수치형 데이터만 될 수 있다. # 아님, 수치형뿐만 아니라 범주형도 가능
⑤ Label은 분류 문제에서는 카테고리, 회귀 문제에서는 수치값이 될 수 있다. # 맞음

## Q4. 지도학습(Supervised Learning)에 대한 설명으로 옳은 것은?

① 입력 데이터만 있고 정답(라벨)이 없는 데이터로 학습한다. # 지도학습은 정답이 있는 데이터로 학습하고 비지도학습이 정답이 없는 데이터로 학습함
*②* 새로운 입력에 대해 정답을 잘 맞추는 함수를 학습한다. # 맞음, 목표가 훈련데이터를 이용해 학습한 후 테스트데이터에서 오류를 최대한 줄이는데 있음
③ 오버피팅은 훈련 데이터에서의 오류를 최대한 줄이는 것으로 학습이 목표하는 방향이다. # 오버피팅은 훈련데이터에서 오류가 적고 테스트데이터에서 오류가 많은 현상인데 이게 학습 목표는 아님 오히려 학습 목표는 테스트데이터의 오류가 줄이는데 있음
④ 지도학습 모델의 출력은 반드시 범주(카테고리)이다. # 아님 범주뿐만 아니라 수치값도 있음 분류문제는 범주이고 회귀문제는 수치값임
⑤ 지도학습은 측정오차를 최소화하는 것이 목적이다. # 측정오차는 줄이거나 제거할 수 없음 지도학습의 목표는 예측값과 실제값의 차이를 줄이는게 목표임


## Q5. 회귀(Regression) 문제의 특징으로 옳은 것은?

① 스팸/정상 분류와 같은 범주 예측 문제를 다룬다. # 분류문제에 해당
*②* 예측값은 연속적인 숫자(예: 가격, 점수, 온도)로 나온다. # 회귀문제는 수치값이라 정답임 분류문제는 범주(카테고리)
③ 대표적인 성능 지표는 정확도(Accuracy)이다. # 회귀문제에서의 성능 지표는 정밀도와 MSE, 결정계수(R^2)임 분류문제는 정확도와 **뭐지??** *혼동행렬(정밀도, 재현율, F1-score), 분류 손실:교차 엔트로프(Cross Entropy)*
④ 예측 결과는 이산적인 값으로 한정된다. # **이건 뭘까**
⑤ 훈련 데이터와 테스트 데이터의 분포가 다르면 반드시 발생한다. # **이건 뭐지**


## Q6. 혼동행렬에 대한 설명으로 옳지 않은 것은?

① TP(True Positive): 실제 양성을 양성으로 예측한 경우 # TP는 둘다 양성, 예측도 양성, 실제도 양성
② TN(True Negative): 실제 음성을 음성으로 예측한 경우 # TN은 둘다 음성, 예측도 음성, 실제도 음성
③ FP(False Positive): 실제 음성인데 양성으로 잘못 예측한 경우 # FP는 양성으로 잘못 예측한 것 예측은 양성, 실제는 음성
④ FN(False Negative): 실제 양성인데 음성으로 잘못 예측한 경우 # FN은 음성으로 잘못 예측한 것 예측은 음성, 실제는 양성
*⑤* 혼동행렬은 회귀 문제의 성능 평가에서 사용된다. # 혼동행렬은 분류문제의 성능평가에서 사용


## Q7. 훈련 오류와 테스트 오류에 대한 설명으로 옳은 것은?

① 훈련 오류는 새로운 데이터에 대한 예측 정확도를 측정한다. # 아님, 훈련 오류는 학습하기 위한 데이터의 오류임, 새로운 데이터는 테스트 오류임
② 테스트 오류는 학습에 사용된 데이터에 대해 계산한 평균 오차이다. # 아님, 훈련 오류임
*③* 궁극적으로 테스트 오류를 최소화하는 것이 학습의 목적이다. # 맞음, 테스트데이터가 실제 데이터이기 때문에 테스트 오류를 줄이는 것이 목표임
④ 일반적으로 훈련 오류는 테스트 오류보다 크게 나타난다. # 아님, 일반적으로는 테스트 오류가 더 크게 나타남, 훈련오류는 많이 학습하다 보면 작아지는게 당연함
⑤ 훈련 오류는 항상 0에 수렴해야 좋은 모델이다. # 아님, 테스트오류가 작을 수록 좋은 모델임, 훈련 오류가 0에 수렴하면서 테스트오류가 높으면 오버피팅임


## Q8. 언더피팅과 오버피팅의 특징을 올바르게 설명한 것은?

*①* 언더피팅은 훈련 오류와 테스트 오류 모두 크게 나타난다. # 맞음, 언더피팅은 학습을 적게한거로 훈련오류, 테스트오류 둘다 크게 나타남
② 언더피팅은 모델이 지나치게 복잡해 데이터 잡음까지 학습하는 현상이다. # **흠... 오버피팅이 데이터 잡음까지 학습하는 현상으로 알고 있는데 한번 확인해봐야할 듯,, 정확하지 않아**

④ 오버피팅은 훈련 오류가 크고 테스트 오류가 작게 나타난다. # 오버피팅은 훈련오류가 작고 테스트오류가 크게나타나는 현상임 훈련데이터에 과접합인 모습을 띔
⑤ 두 경우 모두 모델 복잡도를 높이면 해결된다. # **언더피팅은 모델 복잡도를 높이면 해결되지만, 오버피팅은 잘 모르겠다 한번 확인해야할 듯**
