## Q18. 거대 언어 모델과 BERT, GPT-1 같은 기존 언어 모델의 차이점으로 올바른 것은?

a) 다음 토큰 예측에 기반한 자기 지도 학습 방법
b) 트랜스포머에 기반한 모델 구조
c) 모델 및 학습 규모가 커지면서 나타난 창발성
d) 이미지와 같은 도메인을 포함한 새로운 멀티 모달 학습 데이터

> **정답: c**
> a), b)는 기존 언어 모델들에서도 적용되고 있으며, 거대 언어 모델은 텍스트 데이터에 대한 다음 토큰 예측을 통한 사전 학습으로 학습되므로 d)와 같은 이미지 데이터를 활용하지 않는다.

## Q19. 지시 학습과 선호 학습에 대해 올바르지 않은 것은?

a) 효과적인 지시 학습을 위해서는 다양한 지시 데이터가 필요하다.
b) 크기가 충분하지 않은 거대 언어 모델은 지시 학습 후에 성능이 떨어질 수 있다.
c) 보상 모델은 사람의 선호를 모방하도록 학습된다.
d) 강화 학습 기반 선호 학습의 모든 과정에는 사람의 개입이 필요하다.

> **정답: d**
> 강화 학습 기반 선호 학습의 1단계(지시 학습), 2단계(보상 모델 학습)에는 사람의 지도가 필요하지만, 3단계(강화 학습)에서는 모델 스스로 응답을 생성하고 보상 모델을 통해 피드백을 받아 학습하므로 사람의 개입이 필요하지 않다.

## Q20. 거대 언어 모델의 다양한 디코딩 알고리즘에 대한 설명으로 올바르지 않은 것은?

a) Greedy Decoding은 가장 확률이 높은 토큰을 다음 토큰으로 생성한다.
b) Beam Search는 확률이 높은 응답 후보를 동시에 고려하기 때문에 더 많은 생성 비용을 필요로 한다.
c) 1 이상의 Temperature를 사용할 경우 더 다양한 응답이 생성될 확률이 감소한다.
d) Top-K Sampling은 생성 확률이 높은 K개의 토큰만을 생성 후보로 두고 확률 값에 따라 무작위로 다음 토큰을 생성한다.

> **정답: c**
> 1 이상의 Temperature를 사용할 경우 생성 확률 분포가 uniform에 가까워지므로 더 다양한 토큰을 생성할 확률이 **증가**한다.

## Q21. 거대 언어 모델의 평가 및 한계에 대해 올바르지 않은 것은?

a) 주어진 질문에 대해 정답을 모르는 경우에도, LLM-as-judge 방식을 통해 생성 응답에 대해 평가할 수 있다.
b) LLM-as-judge 방식을 선호 판단에 활용하는 경우, 길이가 짧은 응답을 선호하는 길이 편향이 있을 수 있다.
c) 최신 거대 언어 모델은 안전성 훈련이 잘 되어 있으므로, 탈옥 현상이 일어나지 않는다.
d) 거대 언어 모델이 생성한 응답은 탐지가 가능할 수 있으므로, 무분별하게 사용해서는 안된다.

> **정답: b**
> LLM-as-judge 방식의 선호 판단에서는 ① 길이가 **긴** 응답을 선호하는 길이 편향, ② 입력 순서에 따른 순서 편향, ③ 동일 모델이 생성한 응답을 선호하는 자기 선호 편향이 있다.

## 문제 67. 다음 중 선호 학습(Preference Learning)의 핵심에 대해 올바르게 설명한 것을 고르시오.

1. 모델이 가장 긴 응답을 생성하게 함
2. 여러 응답 중 사람이 더 선호하는 것을 학습
3. 모델이 무작위로 응답을 생성
4. 여러 응답 중 가장 좋은 응답을 모델이 스스로 판단하여 학습

> **정답: 2**
> 선호 학습은 동일한 프롬프트에 대한 여러 응답을 **사람이 비교·순위화한 데이터**로 보상 모델을 학습하고, 그 보상을 따라 모델을 정렬(alignment)하는 방식이다.
> - 4는 사람의 선호를 반영한다는 전제를 벗어나므로 오답이다.
> - 1의 "긴 응답 선호"는 학습 목표가 아니라 오히려 경계해야 할 **길이 편향**이다.

## 문제 70. RLHF 파이프라인의 일반적 단계로 옳은 것은?

1. 사전학습 → 프롬프트 엔지니어링 → 보상 모델 제거
2. 지도학습 → 보상 모델 학습 → 정책 최적화
3. 지도학습 없이 바로 정책 최적화
4. 보상 모델 학습 없이 인간이 직접 강화학습 수행

> **정답: 2**
> RLHF는 ① 지도 미세조정(SFT, 지시 학습) → ② 사람의 선호 비교 데이터로 보상 모델 학습 → ③ 보상 모델을 이용한 강화학습(PPO 등) 정책 최적화의 3단계로 구성된다.
> 사람의 개입은 ①·②까지이며, ③에서는 모델이 스스로 응답을 생성하고 보상 모델이 대신 피드백을 준다.
