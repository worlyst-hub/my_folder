## 문제 12. One-hot Representation(원-핫-인코딩)에 대한 설명으로 옳지 않은 것을 고르시오.

1. 차원이 매우 커져 계산량이 증가한다.
2. 단어 간의 유사도는 항상 1이 나온다.
3. 대부분의 값이 0으로 채워져 메모리 효율이 낮다.
4. "Dog" - "Puppy"의 거리와 "Dog" - "Computer"의 거리는 같다.

> **정답: 2**
> 원-핫 인코딩에서는 모든 단어 벡터가 서로 직교하므로 내적이 항상 0이 된다. 즉 단어 간 유사도는 항상 0이며, 의미적 유사성을 전혀 반영하지 못한다. 4번은 옳은 설명으로, 원-핫 인코딩의 단점이다.

## 문제 60. CBOW와 Skip-gram의 차이점에 대한 설명으로 옳은 것을 고르시오.

1. CBOW는 Skip-gram보다 적게 등장하는 단어에 대해 더 높은 정확도를 보인다.
2. CBOW는 Skip-gram보다 학습이 빠르고, 빈도가 높은 단어에서 성능이 좋다.
3. Skip-gram은 학습 속도는 빠르지만 드물게 등장하는 단어에 약하다.
4. Skip-gram은 한번에 여러 단어를 예측한다.

> **정답: 2**
> - CBOW: 주변 단어들로 중심 단어를 예측 → 학습이 빠르고 빈출 단어에 강함
> - Skip-gram: 중심 단어로 주변 단어들을 예측 → 학습이 느리지만 희귀 단어에 더 강함
> - 3번은 오답: Skip-gram은 드문 단어에 **강하다**.
> - 4번은 오답: Skip-gram은 중심 단어 하나로 여러 주변 단어를 예측하지만, 한 번에 여러 단어를 동시에 예측하는 구조는 아니다.
